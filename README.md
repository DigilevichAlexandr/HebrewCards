# Hebrew Cards

Веб-приложение для изучения слов на иврите по карточкам.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:5173

## Возможности

- **Учить** — режим карточек с переворотом, навигацией и перемешиванием
- **Добавить** — создание новых карточек через интерфейс
- **Список** — просмотр и удаление карточек

Карточки сохраняются в localStorage браузера.

## Сборка

```bash
npm run build
```
